# Comunicação Serial (Simulador)

Projeto desenvolvido em C utilizando o framework ESP-IDF, explorando as principais interfaces de comunicação serial (I²C, SPI e UART) empregadas em sistemas IoT. O sistema deverá coletar dados de sensores, armazenar informações e exibir mensagens, demonstrando domínio prático de integração entre periféricos.
